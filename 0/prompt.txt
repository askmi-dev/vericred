VeriCred’s job is to let an authorized person turn that existing record into a signed credential, deliver it to the right person’s wallet, and revoke it when necessary. The holder can later choose what to share. miTch handles presentation. The product promise in the repo is that an organization can reach its first issuance in under 30 minutes without writing code. Architecture plan (implementation_plan_v2.md)

There is a real issuer implementation here. The console lets an operator select a holder and a credential type and generate an offer. The gateway has code to look up the record, map fields to claims, optionally let the holder review them, validate the wallet’s proof, and issue a signed SD-JWT credential with revocation information.
